# Melhem Final

Deployment instructions

1. Serve the directory with a static server (e.g., `npx serve .` or any web server).
2. Place your product images in the `images/` folder.
3. Edit `index.html`, `product.html`, and `admin.html` and add your content.

Files:
- `index.html` — Main brand page
- `product.html` — Dynamic product page
- `admin.html` — Admin management page
- `css/style.css` — All styles
- `js/` — JavaScript files (see list)
- `images/` — Product images
